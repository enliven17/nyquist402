## Connect a Stellar testnet wallet

Open [/demo](/demo), select **Testnet** in a supported Stellar wallet and connect the account you want to use as the buyer. You need test XLM for account reserves and transaction fees, plus test USDC for the work budget.

Sign the service sign-in challenge to access private history and case material. This challenge is never broadcast and does not fund a payment. Each fund movement requires its own transaction authorization.

## Add USDC and fund your test balance

Choose **Add USDC trustline**, review the asset and sign the trustline transaction. Then open [Circle's faucet](https://faucet.circle.com/), select **USDC / Stellar Testnet** and enter your connected account address. Return to the demo after funding; the displayed balance refreshes automatically.

| Setting | Value |
| --- | --- |
| Network | Stellar Testnet |
| RPC | `https://soroban-testnet.stellar.org` |
| Network passphrase | `Test SDF Network ; September 2015` |
| Asset code | `USDC` |
| USDC issuer | `GBBD47IF6LWK7P7MDEVSCWR7DPUWV3NY3DTQEVFL4NAT4AQH3ZLLFLA5` |
| Amount precision | Seven decimals; 1 USDC = `10000000` base units |

Test XLM and test USDC serve different purposes. USDC funds the agreement; XLM covers Stellar reserves and network fees.

## Protected escrow deployments

| Version | Stellar testnet contract | Payment model |
| --- | --- | --- |
| Protected escrow | `CBX657PJAHLHBNVZASBJPRJFKWKYAGFCKMEE5A57I3ZNPWO5RPKPOMEH` | Work budget, protocol-fee reserve and arbitration reserve |
| Basic auth-capture | `CCB3W5542IQIVWT3ZDTSQIN2LPRMVYLZ2KKQOJT2CTIIDDTYIQVHHCCI` | Spending hold and seller-consented capture |

The client must match the network and contract version before requesting a signature. Each funded payment stays bound to its original deployment and terms. Confirm the fee breakdown shown by the offer rather than inferring fees from the contract version.

## Start a payment

Follow the [demo walkthrough](/docs/quickstart) to fund a budget, record deliveries, accept or dispute a claim and return unused funds. Keep the payment ID and transaction hashes so you can recover the state after reconnecting.

The demo uses test assets. Mainnet service is **not fully implemented yet**; see the [service roadmap](/docs/roadmap).
